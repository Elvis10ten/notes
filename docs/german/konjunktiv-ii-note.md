# German 14: Konjunktiv II
Konjunktiv II marks something as **not real**: a wish, a hypothesis, a suggestion, or a softened request.

| Function           | Example                                        | English                    |
|--------------------|------------------------------------------------|----------------------------|
| Politeness         | **Könnten** Sie mir helfen?                    | Could you help me?         |
| Wish               | Ich **hätte** gern einen Kaffee.               | I’d like a coffee.         |
| Unreal condition   | Wenn ich Zeit **hätte**, **würde** ich kommen. | If I had time, I’d come.   |
| Advice             | Du **solltest** mehr schlafen.                  | You should sleep more.     |
| Cautious statement | Das **wäre** möglich.                          | That would be possible.    |
| Unreal comparison  | Er tut so, als ob er krank **wäre**.           | He acts as if he were ill. |
## 1. The two ways to build it
### i. `würde` + Infinitiv (the default)
Works with almost every verb. **würde** is conjugated; the infinitive goes to the end. e.g.,
* Ich **würde** morgen gern nach Berlin **fahren**.
* **Würdest** du mir bitte **helfen**?

With subordinate clauses, the würde comes after the infinitive. e.g.,
* …, wenn ich in Berlin **wohnen würde**.

### ii. Original form for a small closed set
A handful of very frequent verbs have their own Konjunktiv II form that is used instead of **würde**.
| Infinitive | Präteritum | Konjunktiv II |
|------------|------------|---------------|
| sein       | war        | wäre          |
| haben      | hatte      | hätte         |
| werden     | wurde      | würde         |
| können     | konnte     | könnte        |
| wissen     | wusste     | wüsste        |
| kommen     | kam        | käme          |
| gehen      | ging       | ginge         |
Formation rule: Präteritum (ich-form) + Umlaut (only on a, o, u) + endings -e, -est, -e, -en, -et, -en.

The original form verb is in position 2. e.g.,
* Das **wäre** super.
* Ich **hätte** gern die Rechnung.

With modal verbs, the modal takes position 2, and the infinitive goes to the end. e.g.,
* Er **könnte** recht haben.
* Du **solltest** früher ins Bett **gehen**.

With subordinate clauses, the conjugated verb goes last. e.g.,
* …, wenn ich mehr Geld **hätte**.
## 2. The form to know
|           | sein  | haben   | werden  |
|-----------|-------|---------|---------|
| ich       | wäre  | hätte   | würde   |
| du        | wärst | hättest | würdest |
| er/sie/es | wäre  | hätte   | würde   |
| wir       | wären | hätten  | würden  |
| ihr       | wärt  | hättet  | würdet  |
| sie/Sie   | wären | hätten  | würden  |
*wärst / wärt* also appear as *wärest / wäret*; both are correct.
### Modal verbs
| Infinitive | Konjunktiv II | Note      |
|------------|---------------|-----------|
| können     | könnte        | umlaut    |
| müssen     | müsste        | umlaut    |
| dürfen     | dürfte        | umlaut    |
| mögen      | möchte        | umlaut    |
| sollen     | sollte        | no umlaut |
| wollen     | wollte        | no umlaut |
Endings are the same for all six: -e, -est, -e, -en, -et, -en. e.g., ich könnte, du könntest, er könnte, wir könnten, ihr könntet, sie könnten.

**sollte / wollte** look exactly like the Präteritum. Context decides:
* Ich **wollte** gestern anrufen. (past, indicative)
* Du **solltest** zum Arzt gehen. (advice, Konjunktiv II)
