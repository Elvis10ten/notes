# Subordinate clauses
A subordinate clause cannot stand alone. It’s introduced by:
* A subordinating conjunction
* A relative pronoun or
* A question word

Three things always apply:
| Rule                | Detail                                                       |
|---------------------|--------------------------------------------------------------|
| Comma               | A subordinate clause is always separated by a comma.         |
| Verb last           | The finite verb takes the final slot; any infinitive or participle sits directly before it. Exception: Perfekt + modal (double infinitive), where the finite *habe/hatte* moves in front of the two infinitives. |
| Conjunction ≠ field | The conjunction sits outside the clause proper; it does not count as position 1. |
## 1. Word order inside the subordinating clause
Everything between the conjunction and the verb follows normal **Mittelfeld** order, i.e., Konjunktion + Subjekt + Mittelfeld (Temporal-Kausal-Modal-Lokal) + Verbkomplex.

| Structure                            | Example                                       | Verb block at the end  |
|--------------------------------------|-----------------------------------------------|------------------------|
| Simple verb                          | …, weil ich müde **bin**.                     | bin                    |
| Modal verb                           | …, weil ich arbeiten **muss**.                | arbeiten muss          |
| Separable verb (written as one word) | …, weil er früh **aufsteht**.                 | aufsteht               |
| Perfekt                              | …, weil ich geschlafen **habe**.              | geschlafen habe        |
| Präteritum                           | …, weil ich keine Zeit **hatte**.             | hatte                  |
| Futur I                              | …, weil er kommen **wird**.                   | kommen wird            |
| Passiv                               | …, weil das Auto repariert **wird**.          | repariert wird         |
| Perfekt + Modal (double infinitive)  | …, weil ich nicht **habe** kommen **können**. | **habe** kommen können |
**nicht** stands directly before the verb complex, or before a predicative adjective/noun or a prepositional/directional complement. e.g.,
* …, weil ich das Buch **nicht** lese.
* …, weil ich **nicht** kommen kann.
* …, weil ich **nicht** müde bin.
* …, weil ich **nicht** nach Bonn fahre.

## 2. Position of the subordinating clause
* After the main clause (default). e.g., Ich bleibe zu Hause, **weil ich krank bin**.
* Before the main clause. Then the whole subordinating clause counts as position 1, so the main-clause verb comes immediately after the comma. e.g., **Weil ich krank bin, bleibe** ich zu Hause; **Wenn ich Zeit habe, rufe** ich dich an.

## 3. Subordinating conjunctions
| Konjunktion      | Meaning                                                      | Example                                                      |
|------------------|--------------------------------------------------------------|--------------------------------------------------------------|
| dass             | that. Used after verbs of saying, thinking, knowing, and after expressions of feeling. Verbs like: glauben, denken, meinen, hoffen, sagen, etc. | Ich weiß, dass er kommt.<br>Ich glaube, **dass** er recht **hat**.<br>Es ist schade, **dass** du nicht **kommst**. |
| ob               | whether / if (yes-no)                                        | Ich frage, ob er kommt.                                      |
| weil             | because                                                      | Ich gehe, weil es spät ist.                                  |
| da               | since (known reason, formal)                                 | Da es regnet, bleiben wir hier.                              |
| wenn             | if / when (present, future, conditional; repeated past)      | Wenn ich Zeit habe, komme ich.                               |
| als              | when (single event or one-time period, past)                 | Als ich klein war, wohnte ich in Bonn.                       |
| obwohl           | although                                                     | Ich gehe, obwohl ich müde bin.                               |
| damit            | so that (purpose)                                            | Ich lerne, damit ich die Prüfung bestehe.                    |
| bevor            | before                                                       | Bevor ich gehe, esse ich.                                    |
| nachdem          | after                                                        | Nachdem ich gegessen hatte, ging ich.                        |
| während          | while / whereas                                              | Während er kocht, deckt sie den Tisch.                       |
| bis              | until                                                        | Warte, bis ich fertig bin.                                   |
| seit /seitdem    | since (time)                                                 | Seitdem er hier wohnt, ist er glücklich.                     |
| sobald           | as soon as                                                   | Sobald er kommt, essen wir.                                  |
| solange          | as long as                                                   | Solange es regnet, bleiben wir.                              |
| falls            | in case                                                      | Falls es regnet, nimm den Schirm.                            |
| so dass / sodass | so that (result)                                             | Er sprach leise, sodass ich nichts verstand.                 |
| indem            | by -ing (method)                                             | Man lernt, indem man übt.                                    |
## 4. Key contrasts
|      | Type                                        | Word order               |
|------|---------------------------------------------|--------------------------|
| weil | subordinating                               | verb last                |
| denn | coordinating (position 0)                   | normal main-clause order |
| da   | subordinating, formal, reason already known | verb last                |
## 5. Indirect questions
The question becomes a subordinating clause: verb last. The punctuation follows the main clause: *Ich weiß nicht, wo er wohnt.* / *Weißt du, wo er wohnt?*
| Direct             | Indirect                             |
|--------------------|--------------------------------------|
| Wo wohnt er?       | Ich weiß nicht, **wo** er **wohnt**. |
| Wann kommt sie?    | Sag mir, **wann** sie **kommt**.     |
| Wie geht das?      | Ich weiß nicht, **wie** das **geht**. |
| Kommt er? (yes/no) | Ich frage, **ob** er **kommt**.      |
**Rule**: W-question, keep the W-word. Yes/no question, use **ob**.
