# Komparativ & Superlativ

## 1. The three forms

| Positiv | Komparativ | Superlativ |
|---|---|---|
| schnell | schnell**er** | am schnell**sten** / der schnell**ste** |
| Tom ist schnell. | Tom ist schneller **als** Max. | Tom ist am schnellsten. / Tom ist der schnellste Spieler. |

---

## 2. Komparativ

### Formation: adjective + **-er**
klein → klein**er** · schön → schön**er** · billig → billig**er** · interessant → interessant**er**

German never uses *mehr + adjective* for the comparative.
✗ mehr interessant → ✓ interessant**er**

### Umlaut: most short adjectives with a, o, u
| a → ä | o → ö | u → ü |
|---|---|---|
| alt → älter, lang → länger, warm → wärmer, kalt → kälter, stark → stärker, arm → ärmer, hart → härter, krank → kränker, nah → näher | groß → größer, hoch → höher, oft → öfter | jung → jünger, kurz → kürzer, klug → klüger, gesund → gesünder, dumm → dümmer |

**No umlaut**: laut, klar, froh, voll, rund, bunt, schlank, flach, langsam — and all longer adjectives (interessant, langweilig, …).

### Small spelling changes
- **-el / -er** drop the e: dunkel → dunk**ler**, teuer → teu**rer**, sauer → sau**rer**
- ending in **-e**: only add -r: leise → leise**r**, müde → müde**r**

### Irregular forms (must know)
| Positiv | Komparativ | Superlativ |
|---|---|---|
| gut | besser | am besten |
| viel | mehr | am meisten |
| gern | lieber | am liebsten |
| hoch | höher | am höchsten |
| nah | näher | am nächsten |
| groß | größer | am größten |
| oft | öfter | am häufigsten |

### Comparing: **als** vs. **wie**
- Komparativ + **als** → Berlin ist größer **als** Hamburg.
- **so / genauso** + Positiv + **wie** → Berlin ist nicht so warm **wie** Rom. · Er ist genauso alt **wie** ich.

✗ größer *wie* ich (colloquial, wrong in the exam) → ✓ größer **als** ich
✗ so groß *als* → ✓ so groß **wie**

### Strengthen or soften
**viel / noch / etwas / ein bisschen** + Komparativ
- Die neue Wohnung ist **viel** größer.
- Kannst du **etwas** langsamer sprechen?
- Heute ist es **noch** kälter als gestern.

## 3. Superlativ

### Two forms
1. **am + -sten** → after a verb, no noun follows
   Im Juli ist es **am wärmsten**. · Sie läuft **am schnellsten**. · Was magst du **am meisten**?
2. **der / die / das + -ste** → before a noun, or used as a noun
   Das ist **das schnellste** Auto. · Sie ist **die Beste**.

Both are correct after *sein*: Er ist am schnellsten. = Er ist der Schnellste.

### -est after **d, t, s, ß, z, sch, x**
alt → am ält**est**en · laut → am laut**est**en · heiß → am heiß**est**en · kurz → am kürz**est**en · hübsch → am hübsch**est**en · interessant → am interessant**est**en
**Exception:** groß → am grö**ßt**en (not *größesten*)

### Naming the group: **von / in / unter**
Sie ist die Beste **von** allen. · Berlin ist die größte Stadt **in** Deutschland. · Er ist der Jüngste **unter** uns.

## 4. Before a noun: adjective endings

Komparativ and Superlativ before a noun take the **normal adjective endings**, added after *-er* / *-st*.

| | der / die / das | ein / kein / mein |
|---|---|---|
| Nom. m | der älter**e** / ältest**e** Bruder | ein älter**er** / mein ältest**er** Bruder |
| Nom. f | die älter**e** / ältest**e** Schwester | eine älter**e** / meine ältest**e** Schwester |
| Nom. n | das älter**e** / ältest**e** Kind | ein älter**es** / mein ältest**es** Kind |
| Akk. m | den älter**en** / ältest**en** Bruder | einen älter**en** / meinen ältest**en** Bruder |
| Akk. f / n | = Nominativ | = Nominativ |
| Dat. (all) | dem/der älter**en** / ältest**en** … | einem/einer älter**en** / meinem ältest**en** … |
| Plural Nom./Akk. | die älter**en** / ältest**en** Kinder | meine älter**en** / ältest**en** Kinder |

Examples:
- Ich suche eine **billigere** Wohnung. · Wir nehmen den **kürzeren** Weg. · Ich spiele mit meinem **jüngeren** Bruder.
- Das ist der **beste** Spieler. · Ich nehme den **billigsten** Flug. · Sie wohnt im **höchsten** Haus der Straße.

Superlativ before a noun always has *der/die/das* or *mein/dein…* — never *am*.
✗ die *am besten* Idee → ✓ die **beste** Idee

## 5. Patterns you need for the exam

**lieber / am liebsten** (preferences)
Ich trinke lieber Tee als Kaffee. · Am liebsten spiele ich Fußball.

**mehr / weniger** before a noun → no ending
Ich habe mehr Zeit, aber weniger Geld.

**immer + Komparativ** ("more and more")
Die Mieten werden immer teurer. · Mein Deutsch wird immer besser.

**je … desto / umso** (B1)
Je mehr ich übe, **desto** besser wird mein Deutsch. · Je früher du kommst, **umso** besser.
Word order: *Je* + Komparativ … **verb at the end** | *desto* + Komparativ + **verb** + subject.

## 6. Common mistakes

| ✗ Wrong | ✓ Right | Why |
|---|---|---|
| mehr schnell | schneller | no *mehr + adjective* |
| größer wie ich | größer als ich | Komparativ + *als* |
| so gut als ich | so gut wie ich | *so … wie* |
| guter / am gutesten | besser / am besten | irregular |
| am größesten | am größten | *groß* is the exception |
| die am besten Idee | die beste Idee | no *am* before a noun |
| mehre Zeit | mehr Zeit | *mehr / weniger* take no ending |
| teuerer | teurer | *-er* drops the e |
| Je mehr ich lerne, desto ich verstehe besser. | …, desto besser verstehe ich. | *desto* + Komparativ + verb |
