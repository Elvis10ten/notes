Plurals

1. When to use -s

  • Loanwords: e.g., das Hotel -> Hotels; das Restaurant -> Restaurants; der Chef -> Chefs; das Team -> Teams; das Handy -> Handys; die Party -> Partys.
  • Nouns ending in a vowel other than -e: e.g., das Auto -> Autos; das Sofa -> Sofas; das Kino -> Kinos; das Büro -> Büros; die Oma -> Omas.
  • Abbreviations: e.g., der Lkw -> Lkws; die AG -> AGs.
  • Family names: die Müllers; die Schmidts.

2. Predicting by Gender + Suffix

2.1. Feminine

Feminine plurals essentially always end in -n, except the closed umlaut + -e set and -s loanwords.

  • -e, -el, -er -> -n. e.g., die Blume -> Blumen; die Regel -> die Regeln; die Schwester -> die Schwestern.
  • -heit, -keit, -ung, -schaft -> -en. e.g., die Wohnung -> Wohnungen.
  • -ion, -ität, -ik, -enz, -anz, -ur -> -en. e.g. die Nation -> Nationen; die Universität -> Universitäten.
  • -in -> -inen. e.g., die Lehrerin -> Lehrerinnen.
  • A small closed set of one-syllable feminines takes umlaut + -e. e.g., die Hand -> Hände; die Stadt -> Städte; die Nacht -> Nächte; die Kraft -> Kräfte; die Wand -> Wände; die Maus -> Mäuse; die Kuh -> Kühe; die Wurst -> Würste.
  • Umlaut only: die Mutter -> Mütter; die Tochter -> Töchter.
  • Feminine default -en for nouns not covered by the suffix lists. e.g., die Frau → Frauen; die Zeit → Zeiten; die Uhr → Uhren; die Tür → Türen.

2.2. Masculine

  • Most one-syllable noun -> -e (+/- umlaut). e.g., der Hund -> Hunde; der Stuhl -> Stühle.
  • -er, -el, -en -> -∅ (+/- umlaut). e.g., der Lehrer -> Lehrer; der Apfel -> Äpfel; der Garten -> Gärten.
  • -ling, -ich, -ig -> -e (no umlaut). e.g., der Lehrling -> Lehrlinge; der König -> Könige.
  • -or -> -en (stress shifts). e.g., der Professor -> Professóren; der Motor -> Motoren.
  • weak (n-) nouns: -e, -ent, -ant, -ist, -oge -> -(e)n. e.g., der Junge -> Jungen; der Student -> Studenten; der Polizist -> Polizisten.

2.3. Neuter

  • Neuter -er, -el, -en, -chen, -lein -> -∅ (no umlaut). e.g., das Fenster → Fenster; das Mädchen → Mädchen; das Zimmer → Zimmer.
  • Ge- .. -e -> -∅. e.g., das Gebäude -> Gebäude.
  • Many one-syllable nouns -> -er + umlaut. e.g., das Buch -> Bücher; das Haus -> Häuser; das Land -> Länder; das Glas -> Gläser.
  • Other one/two-syllable nouns -> -e (no umlaut). e.g., das Jahr -> Jahre; das Boot -> Boote.
  • -um (Latin) -> -umen. e.g., das Museum -> Museen; das Zentrum -> Zentren.
  • -nis -> - nisse. e.g., das Ergebnis -> Ergebnisse.
  • -ment, -at -> -e. e.g., das Instrument -> Instrumente.
  • Oddities that take -en. e.g., das Auge -> Augen; das Ohr -> Ohren; das Bett -> Betten; das Hemd -> Hemden; das Herz -> Herzen.

3. Irregulars

  • das Thema -> die Themen
  • die Firma -> die Firmen
  • das Praktikum-> die Praktika
  • das Visum -> die Visa
  • das Album -> die Alben
  • der Kaktus -> die Kakteen
  • der Rhythmus -> die Rhythmen
  • der Atlas -> die Atlanten
  • Plural only words: e.g., die Eltern, die Geschwister, die Leute, die Ferien, die Kosten.
  • Singular only: e.g., das Obst, das Gemüse, das Fleisch, die Milch, der Zucker, das Glück, die Liebe, die Polizei.
