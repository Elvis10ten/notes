# German 5: Separable & inseparable verbs
German builds huge families of verbs by attaching a prefix to a base verb.

| Base                 | + prefix      | Meaning             |
|----------------------|---------------|---------------------|
| **kommen** (to come) | **an**kommen  | to arrive           |
|                      | **be**kommen  | to receive          |
|                      | **mit**kommen | to come along       |
|                      | **ent**kommen | to escape           |
|                      | **um**kommen  | to perish           |
|                      | **vor**kommen | to occur, to happen |
* With **separable verbs**, the prefix flies to the end of the clause when you conjugate it.
* With **inseparable verbs**, the prefix stays welded on, always.

## 1. Inseparable prefixes
* be-
* emp-
* ent-
* er-
* ge-
* miss-
* ver-
* zer-

Some example verbs:
| Verb            | Meaning       |
|-----------------|---------------|
| **be**suchen    | to visit      |
| **emp**fehlen   | to recommend  |
| **ent**scheiden | to decide     |
| **er**klären    | to explain    |
| **ge**hören     | to belong     |
| **miss**lingen  | to fail       |
| **ver**stehen   | to understand |
| **zer**stören   | to destroy    |

| Verb            | Meaning         |
|-----------------|-----------------|
| **an**rufen     | to call (phone) |
| **auf**stehen   | to get up       |
| **ein**kaufen   | to shop         |

| **um**ziehen    | to move house   |
*Note:* `um-` is a dual prefix (see §3). **um**ziehen (to move house) happens to be one of its always-separable members.
## 3. The dual prefixes: separable or inseparable
* durch-
* hinter-
* über-
* um-
* unter-
* voll-
* wider-
* wieder-

These go both ways, and the difference is meaningful:
* Concrete / physical meaning → tends to be separable (prefix stressed).
* Figurative / abstract meaning → tends to be inseparable (stem stressed).

| Infinitive   | Separable (stressed prefix)                                 | Inseparable (stressed stem)                          |
|--------------|-------------------------------------------------------------|------------------------------------------------------|
| umfahren     | Ich fahre den Baum **um**. (I knock the tree down)          | Ich um**fah**re den Baum. (I drive around the tree)  |
| übersetzen   | Der Fährmann setzt uns **über**. (ferries us across)        | Sie über**setzt** den Text. (translates the text)    |
| durchschauen | Ich schaue die Unterlagen **durch**. (look through/review)  | Ich durch**schaue** dich. (I see through you)        |
| wiederholen  | Ich hole das Buch **wieder**. (fetch it back)               | Ich wieder**hole** den Satz. (I repeat the sentence) |
| unterhalten  | Er hält den Schirm **unter**. (holds it underneath)         | Wir unter**halten** uns. (we chat)                   |

> **Treat the concrete/figurative split as a tendency, not a rule.** *umfahren* already breaks it: the inseparable form (*I drive around the tree*) is perfectly spatial, while the separable one (*knock down*) is the one involving physical contact. A better rough guide for the inseparable forms is that the prefix makes the object directly affected or "covered" by the action. Stress and meaning ultimately have to be learned verb by verb.

Fixed one-way members of these dual families:
| Always separable                  | Always inseparable                 |
|-----------------------------------|------------------------------------|
| **unter**gehen (to set, to sink)  | unter**schreiben** (to sign)       |
| **unter**bringen (to accommodate) | unter**brechen** (to interrupt)    |
| **durch**fallen (to fail an exam) | um**armen** (to hug)               |
| **um**ziehen (to move house)      | über**holen** (to overtake)        |
| **wieder**sehen (to see again)    | wider**sprechen** (to contradict)  |
| **voll**tanken (to fill the tank) | hinter**lassen** (to leave behind) |
## 4. Word order

| Context                            | Separable — anrufen              | Inseparable — besuchen            |
|------------------------------------|----------------------------------|-----------------------------------|
| Present / Präteritum (main clause) | Ich **rufe** dich **an**.        | Ich **besuche** dich.             |
| Subordinate clause                 | …, weil ich dich **anrufe**.     | …, weil ich dich **besuche**.     |
| Perfekt                            | Ich habe dich **an**ge**rufen**. | Ich habe dich **besucht**.        |
| Modal verb                         | Ich muss dich **anrufen**.       | Ich muss dich **besuchen**.       |
| Future I                           | Ich werde dich **anrufen**.      | Ich werde dich **besuchen**.      |
| zu-infinitive                      | Ich vergaß, dich **anzurufen**.  | Ich vergaß, dich **zu besuchen**. |
| Imperative                         | **Ruf** mich **an**!             | **Besuch** mich!                  |
